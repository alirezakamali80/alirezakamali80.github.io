## Overview

This project explored deep-learning methods for scene understanding and object detection in driving and UAV imagery.

## Models and Tasks

- Fine-tuned ViT-B/16 for driving-scene classification.
- Fine-tuned ResNet-50 for driving-scene classification.
- Trained YOLOv11 for UAV object detection.
- Used BDD100K-style driving scenes and VisDrone-style aerial imagery.

## Evaluation

- ROC curves and AUC
- Mean average precision (mAP)
- Precision and recall
- Confusion matrices
- Inference speed
- Qualitative detection examples
