## Overview

This project developed a custom Gymnasium-style simulation environment for a one-link robotic arm and compared multiple reinforcement-learning algorithms for swing-up and stabilization.

## Algorithms

- SARSA
- Q-learning
- Deep Q-Network (DQN)
- Soft Actor-Critic (SAC)

## Evaluation

Performance was evaluated using:

- Success rate
- RMS angle error
- Control effort
- Cumulative reward
- Closed-loop state trajectories
- Swing-up and stabilization behavior

## Keywords

Reinforcement learning, robotic arm, nonlinear control, Q-learning, SARSA, DQN, SAC, Gymnasium
